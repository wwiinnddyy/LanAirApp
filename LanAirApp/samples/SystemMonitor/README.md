# SystemMonitor：历史 AirApp 原型

此目录是第三方 AirApp API 1.0.0 时期的历史设计原型，当前生产宿主不能安装或加载它。它被有意排除在 `LanAirApp.slnx`、CI、Plugin SDK 5 打包流程和市场 registry 之外；请勿把版本字符串改成 6.0.0 后冒充已完成迁移。

完整阻塞与迁移条件见 [`../LEGACY_AIRAPP_SAMPLES.md`](../LEGACY_AIRAPP_SAMPLES.md)。当前可用示例请参阅 [`../LanMountainDesktop.SamplePlugin`](../LanMountainDesktop.SamplePlugin/README.md)。
